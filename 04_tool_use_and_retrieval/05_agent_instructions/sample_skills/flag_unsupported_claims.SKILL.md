# Flag unsupported claims

1. Read the text and list every sentence that states a specific fact: a number, a date, a comparison, an attribution to a named person or study.
2. For each one, note whether the text itself gives a source. Do not search the web to check whether the claim is *true*; only check whether it is *sourced*.
3. Leave opinions, predictions, and clearly labeled speculation off the list; a claim is only in scope if it is phrased as settled fact.
4. Present the result as a numbered list: the claim, quoted, followed by "no source given" or "sourced: <where>".
5. If every claim in the text is already sourced, say so plainly instead of forcing an empty list into the reply.
