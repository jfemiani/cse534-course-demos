# Add hashtags

1. Read the post and pick 3 to 5 hashtags, no more; a wall of tags reads as spam and most platforms rank posts down for it.
2. Prefer specific tags over generic ones. "#MachineLearning" over "#tech", "#SanDiegoHiking" over "#outdoors".
3. Use CamelCase for any multi-word tag ("#TrailRunning", not "#trailrunning"), so screen readers announce it as separate words instead of one run-on string.
4. Place the hashtags on their own line at the end of the post; never interleave them inside a sentence.
5. Do not invent a tag for a brand, place, or person the post does not actually mention.
