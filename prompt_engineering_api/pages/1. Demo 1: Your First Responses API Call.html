Why begin with one request and one response?

In this demonstration, you will run a short Python program that sends a prompt to an AI model and prints the model’s reply.

The AI model does not run on your computer. Your program sends the prompt to OpenAI over the internet. OpenAI processes the prompt and sends a result back to your program.

We will begin with one prompt and one reply. Later demonstrations will build on this example by adding a conversation, displaying a reply as it is generated, and returning information in a format that Python can use reliably.

When you read the code, look for these four steps:

  1. The program chooses which AI model to use.
  2. OpenAI() prepares the connection to OpenAI.
  3. responses.create(...) sends the prompt.
  4. response.output_text gets the text of the reply so the program can print it.

What to notice

  • OpenAI() obtains the key from the environment; the key is not in the file.
  • OPENAI_MODEL lets you change the model without editing the program.
  • response.output_text is a convenience property for the returned text.
