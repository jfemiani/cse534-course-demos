Why conversation state matters

In Demo 1, the program sent one prompt and received one reply. In this demonstration, you will let a person continue the conversation by typing another message.

A follow-up message often depends on an earlier reply. For example, if you type “Make it shorter,” the model needs to know what “it” refers to.

After OpenAI returns a reply, it gives that reply an ID. The program saves the ID in a variable named previous_id. When the person types the next message, the program sends the saved ID as previous_response_id. This tells OpenAI which earlier reply the new message follows.

The program starts with previous_id = None because there is no earlier reply yet. After each reply, it replaces previous_id with the new reply’s ID.
