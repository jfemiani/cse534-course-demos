Why stream a response?

In Demo 2, the program waited for the entire reply before showing anything. In this demonstration, the program will display the reply a little at a time as OpenAI generates it. This is called streaming.

Streaming is useful when a reply takes several seconds. Showing the first words quickly lets the user know that the program is working.

With streaming turned on, the program receives a series of small updates called events. Some events contain new pieces of text. The program prints those pieces as they arrive. A final event tells the program that the reply is complete.

Look for stream=True, which turns streaming on. Then look for the loop that checks each event. The program prints text from response.output_text.delta events and saves the reply ID when it receives response.completed.
