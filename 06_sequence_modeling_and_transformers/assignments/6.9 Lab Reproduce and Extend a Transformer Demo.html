What this lab asks you to do

This module trained the same translation task, on the same corpus and the same five held-out sentences, three times: as a plain RNN, as an LSTM, and as a Transformer. This lab focuses on the Transformer, since attention is the mechanism this module builds up to and the one behind every modern large language model. Choose one change to 05_transformer_mt.py and develop it into a finished submission.

You do not need to repeat the demonstration or retrain a bigger model. Submit one working Python file based on 05_transformer_mt.py, show your changed version running, and explain the one change you made.

1. Start from the Transformer demo

Demo: a small Transformer encoder-decoder, trained on the module's shared English-French corpus, that visualizes which source word the decoder's cross-attention weighted most heavily while generating each output word – 05_transformer_mt.py.

If you need to reinstall the packages, download requirements-sequence-modeling-and-transformers.txt and run python -m pip install -r requirements-sequence-modeling-and-transformers.txt. You will also need mt_data.py from the same module folder, since the demo imports its shared data pipeline from there.

2. Make one small change

Make one change that adds to the original demonstration without replacing its main idea. You may use the suggested change below or propose your own.

  • Suggested change: Add a sixth sentence of your own choosing to EVAL_PAIRS in mt_data.py (or a local copy of it), and extend the demo's evaluation and attention-visualization code so it also reports that sentence's reference loss and prints a cross-attention table for it, in the same style as the module's Table 1 and Table 2. Pick a sentence that is meaningfully different from the module's existing five (for example, noticeably longer, or built from a different sentence structure), and say why you picked it.

If you choose a different change: identify the exact variable, function, or hyperparameter you will alter (for example, N_HEAD, D_MODEL, EPOCHS, or which sentence the attention visualization is printed for) and what specific output you expect to change as a result. "Make the model better" is not specific enough. State which value is being changed, where it appears in the code, and what you expect to see differently in the printed loss table or attention output because of it.

Keep the program small. You do not need a graphical interface, a larger dataset, or a different architecture.

How this lab will be assessed

The lab is worth 100 points. Each part below is based only on evidence contained in the three items you submit.

  • 25 points – The program runs: Your recording or screenshots show the changed program running and producing a visible result.
  • 30 points – The original demonstration's idea remains clear: Your submitted code and evidence still demonstrate the main idea of the Transformer demo: attention as a fresh, learned lookup over the source sentence at every decoding step, not a single fixed-size bottleneck vector.
  • 30 points – Your change is visible and explained: The change appears in the submitted code, works in the recording or screenshots, and is accurately described in your change note.
  • 15 points – The submission is complete and readable: All three required items are present, open correctly, and contain enough information to grade the work.

A grader should not have to guess what you changed or whether it worked. Make the changed code and its result easy to find.
