Back to the API, with more moving parts

Module 2 covered one request and one reply. This module covers what the model can do when it needs outside help: calling code, deciding for itself when to call more code, and answering questions about a document it never saw during training.

This version stays close to what the OpenAI API itself now does out of the box, and names the underlying ideas so they transfer to any vendor's API, rather than tying the lesson to one specific framework.

Key Topics

  • Tool use (function calling): letting the model ask your code to do something, instead of guessing the answer
  • The agent loop: the model calling tools repeatedly, on its own, until it decides it has enough to answer
  • Retrieval-augmented generation (RAG): chunking a document, embedding the chunks, and pulling in the closest ones at answer time
  • Vector search, keyword search, and where each one wins
  • AGENTS.md and SKILL.md: instructions a model reads on demand, instead of tools it calls

Reading

This module does not follow a textbook. The APIs it covers changed enough since the last edition of the assigned reading that a fixed chapter would be out of date within a year. Each lesson page links to the current official documentation it is based on instead. Check those links for anything that may have changed since this page was written.
