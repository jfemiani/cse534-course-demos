# CSE 534 Canvas Page Style

- Section headers use a Miami Red background (#941728) with white text.
- Every embedded code sample is a GitHub iframe embed, not a pasted code block.
- Every image has descriptive alt text.
- Pages open with a paragraph, not a heading that repeats the page title.
