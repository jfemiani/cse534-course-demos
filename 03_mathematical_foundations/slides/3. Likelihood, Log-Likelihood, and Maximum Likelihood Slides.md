# Likelihood, Log-Likelihood, and Maximum Likelihood

Why machine learning uses log-likelihood instead of likelihood

---

## Probability vs. Likelihood

**Probability** and **likelihood** answer different questions about the same model.

**Probability:** Parameters **known** → What **data** might we observe?

**Likelihood:** Data **known** → Which **parameters** make data most plausible?

<!-- stop -->

**Example:** Coin with μ = P(heads)

- **Probability:** If μ = 0.70, what fraction of heads might we see?
- **Likelihood:** After seeing 70% heads in 100 flips, which μ (0.50, 0.60, 0.70) is most plausible?

---

## Independent Observations

For **i.i.d. data** (independent, identically distributed):

```
L(θ; x₁, ..., xₙ) = ∏ᵢ₌₁ⁿ p(xᵢ | θ)
```

<!-- stop -->

**Bernoulli example:**
```
L(μ) = μᵏ (1-μ)ⁿ⁻ᵏ
```
where k = number of 1s, n = total observations

---

## Problem: Numerical Underflow

**Goal:** Find μ that maximizes L(μ)

**But multiplying thousands of probabilities underflows:**
```
L(μ=0.7) = 0.7⁷⁰⁰⁰⁰ · 0.3³⁰⁰⁰⁰ → 0.00e+00  (underflow!)
```

<!-- stop -->

**All candidates underflow to zero** - can't compare them!

**Demo Part A:** See 05a_likelihood_underflow.py

Output: all 4 candidates have L = 0.00e+00

---

## Log-Likelihood Solution

**Key transformation:** Products → Sums
```
ℓ(θ) = log L(θ) = ∑ᵢ₌₁ⁿ log p(xᵢ | θ)
```

**Why this works:**
- log is monotonic: maximizing L = maximizing log L

<!-- stop -->

- Addition is numerically stable

<!-- stop -->

- Gradients stay computable

<!-- stop -->

**For Bernoulli:**
```
ℓ(μ) = ∑ᵢ₌₁ⁿ [xᵢ log μ + (1-xᵢ) log(1-μ)]
```

<!-- stop -->

**Demo Part A revisited:** Log-likelihood stays finite: log L = -693.15

---

## Maximum Likelihood Estimate

**Goal:** Find μ that maximizes ℓ(μ)

**Step 1:** Start with the log-likelihood
```
ℓ(μ) = ∑ᵢ₌₁ⁿ [xᵢ log μ + (1-xᵢ) log(1-μ)]
```

<!-- stop -->

**Step 2:** Take the derivative with respect to μ
```
∂ℓ/∂μ = ∑ᵢ₌₁ⁿ [xᵢ/μ - (1-xᵢ)/(1-μ)]
```

<!-- stop -->

**Step 3:** Set derivative to zero (critical point)
```
∑ᵢ₌₁ⁿ [xᵢ/μ - (1-xᵢ)/(1-μ)] = 0
```

---

## Solving for μ̂_ML

**Step 4:** Separate the sum
```
∑ᵢ₌₁ⁿ xᵢ/μ = ∑ᵢ₌₁ⁿ (1-xᵢ)/(1-μ)
```

<!-- stop -->

**Step 5:** Factor out constants
```
(1/μ) ∑ᵢ₌₁ⁿ xᵢ = [1/(1-μ)] ∑ᵢ₌₁ⁿ (1-xᵢ)
```

<!-- stop -->

**Step 6:** Simplify ∑(1-xᵢ) = n - ∑xᵢ
```
(1/μ) ∑ᵢ xᵢ = [1/(1-μ)] (n - ∑ᵢ xᵢ)
```

---

## Final Result

**Step 7:** Cross-multiply
```
(1-μ) ∑ᵢ xᵢ = μ (n - ∑ᵢ xᵢ)
```

<!-- stop -->

**Step 8:** Expand and collect terms
```
∑ᵢ xᵢ - μ ∑ᵢ xᵢ = μn - μ ∑ᵢ xᵢ
∑ᵢ xᵢ = μn
```

<!-- stop -->

**Step 9:** Solve for μ
```
μ̂_ML = (1/n) ∑ᵢ₌₁ⁿ xᵢ
```

**The ML estimate is the sample mean!**

For 70 heads in 100 flips: μ̂_ML = 70/100 = 0.70

---

## Problem: Gradient Vanishing

**Neural networks use gradient-based optimization:**
```
θ ← θ + α · ∇L(θ)
```

**When L(θ) ≈ 10⁻²⁶⁷:**
- Gradients ∇L(θ) → 0 or NaN
- Parameters don't update
- Optimization fails

<!-- stop -->

**Demo Part B:** See 05b_likelihood_gradient_fail.py

Parameter stuck at 0.3000 - gradients vanish!

---

## Log-Likelihood Success

**Gradient ascent on log-likelihood works:**
```
∂ℓ/∂μ = ∑ᵢ₌₁ⁿ [xᵢ/μ - (1-xᵢ)/(1-μ)]
```

<!-- stop -->

**Demo Part C:** See 05c_likelihood_logit.py

Converges to μ ≈ 0.70 - the true value!

*(Note: requires clamping to keep μ ∈ (0,1))*

## Negative Log-Likelihood as Loss

**Machine learning convention:** Minimize loss functions

**Negative log-likelihood (NLL):**
```
Loss = -ℓ(θ) = -log L(θ)
```

**Maximizing likelihood = Minimizing NLL**

<!-- stop -->

**Used everywhere in ML:**
- Classification: **Cross-entropy loss** = NLL

<!-- stop -->

- Regression: **MSE** = NLL (with Gaussian assumption)

<!-- stop -->

- Neural networks: All trained by minimizing NLL

---

## Connection to Deep Learning

**Training large language models:**
```
Minimize: -log P(text | θ)
```

**Why NLL works at scale:**
1. Log converts product → sum (numerically stable)

<!-- stop -->

2. Gradients stay computable over billions of parameters

<!-- stop -->

3. Standard optimizers (Adam, SGD) minimize loss

<!-- stop -->

**GPT, BERT, etc.:** Minimize NLL over massive text corpora

**This is maximum likelihood estimation via gradient descent!**

---

## Summary

✓ **Probability** vs **Likelihood**: Different questions, same math

✓ **Products underflow**: Raw likelihood → 0 with large datasets

✓ **Log transforms**: Multiplication → addition (stable!)

✓ **Gradients work**: Log-likelihood has computable gradients

✓ **NLL = standard ML loss**: Cross-entropy, MSE are both NLL

**Maximizing likelihood = Minimizing negative log-likelihood**
