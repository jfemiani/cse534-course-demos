Surprise and information

Suppose a language model sees the prompt The capital of France is …. If it assigns a high probability to Paris, observing that token is not surprising. If it assigns a tiny probability to banana and that token nevertheless occurs, the result is much more surprising. This lesson turns that ordinary idea into four related measurements: self-information measures the surprise of one outcome; entropy measures the average surprise within one probability distribution; cross-entropy measures the average surprise when data from one distribution are evaluated using another; and KL divergence measures the extra surprise caused by using the second distribution.

What properties should a measure of surprise have? Think about what makes sense:

  1. Rare events carry more information: If p(x) < p(y), then I(x) > I(y)
  2. Certainty carries no information: If p(x) = 1, then I(x) = 0
  3. Independent events add information: If x and y are independent, I(x, y) = I(x) + I(y)
  4. Information is continuous: Small changes in probability cause small changes in information

These properties uniquely determine the logarithmic form. For independent events, p(x, y) = p(x) · p(y), so we need a function where f(p1 · p2) = f(p1) + f(p2). Logarithms satisfy this: log(ab) = log(a) + log(b). The negative sign makes rare events (small p) give large positive information.

I(x)=−log2p(x)
(4.1)

Equation (4.1) uses a base-two logarithm, written log2, so the unit is bits. An outcome with probability 1/2 carries 1 bit of surprise; an outcome with probability 1/4 carries 2 bits. An event with probability 1 has zero surprise because −log2(1) = 0. Check: this formula satisfies all four properties above.

Entropy: average surprise

Entropy measures the average surprise or uncertainty in a probability distribution. The uppercase H names entropy.

H(p)=−∑x∈𝒳p(x)log2p(x)
(4.2)

Entropy is the expected value of self-information. A deterministic distribution (probability 1 on one outcome) has zero entropy because there is no uncertainty.

Which distribution has maximum entropy? On a fixed finite set of n outcomes, the uniform distribution (every outcome has probability 1/n) maximizes entropy. Intuition: concentrating probability on fewer outcomes makes the distribution more predictable, which reduces uncertainty. Spreading probability uniformly makes each draw maximally unpredictable.

The formal proof uses the fact that −log is a strictly concave function. By Jensen’s inequality, the weighted average −Σp(x)log p(x) is maximized when all p(x) are equal. Below we calculate the entropy of the uniform distribution to find this maximum value.

Calculating maximum entropy: For a discrete distribution with n equally-likely outcomes, each has probability 1/n. Substituting into Equation (4.2):

H=−∑i=1n1nlog21n

Pull the constant 1/n out of the sum:

H=−1n∑i=1nlog21n

The sum has n identical terms:

H=−1n⋅n⋅log21n

Simplify:

H=−log21n

Use logarithm properties (log(1/n) = −log(n)):

H=log2n

Result: For n outcomes, maximum entropy is log2(n) bits, achieved by the uniform distribution. Example: a vocabulary of 50,000 tokens with uniform distribution has entropy log2(50000) ≈ 15.6 bits per token. Any non-uniform distribution over the same vocabulary has lower entropy because some outcomes are more predictable than others.

The maximum entropy principle: When choosing a probability distribution for a model, the uniform distribution (for discrete outcomes) and the Gaussian distribution (for continuous values) are often good default choices because they maximize entropy. Maximum entropy means the distribution imposes the fewest assumptions about the data. If you know nothing except the range of possible values, use uniform. If you know the mean and variance but nothing else, use Gaussian. These distributions avoid building in extra structure or bias that might not actually exist in the real data.

Cross-entropy: measuring model surprise

Cross-entropy measures how surprised a model is by actual data. Here, p is the true data distribution and q is the model's predicted distribution. Cross-entropy computes the expected surprise under p using probabilities from q.

H(p,q)=−∑x∈𝒳p(x)log2q(x)
(4.3)

If the model is perfect (q = p), cross-entropy equals entropy. If the model is wrong, cross-entropy is higher. This is why neural networks minimize cross-entropy loss during training.

Ground truth labels in practice: In classification tasks, the ground truth p is typically a one-hot encoded vector: probability 1 on the correct class and 0 everywhere else. For example, if the correct next token is "Paris", then p(Paris) = 1 and p(x) = 0 for all other tokens. This perfectly confident target can encourage the model to become overconfident, assigning probabilities very close to 0 or 1.

Label smoothing: To prevent overconfidence, a technique called label smoothing replaces the hard one-hot target with a slightly softer distribution. Instead of p(Paris) = 1.0, you might use p(Paris) = 0.9 and spread the remaining 0.1 uniformly across other tokens. This discourages the model from being too certain and often improves generalization.

KL divergence: comparing two distributions

Why KL divergence matters: KL divergence is a tool for answering the question “are these two distributions different?” In generative AI, you often need to evaluate whether a model’s generated distribution matches the real data distribution. For example, does a GAN produce images with the same diversity as real photos? Does a language model generate text with the same word frequency as human writing? KL divergence measures how much one distribution differs from another.

Cross-entropy vs. KL divergence: Both measure mismatch between distributions, but they serve different purposes. Cross-entropy is used during training to optimize model parameters when you have known labels. KL divergence is used during evaluation and analysis to compare two full distributions without necessarily having labels. You compute KL divergence when you want to know whether two probability distributions are similar, such as comparing generated samples to real data.

Definition: Kullback-Leibler divergence (KL divergence) measures how much extra surprise we get from using distribution q instead of the true distribution p.

DKL(p∥q)=∑x∈𝒳p(x)log2p(x)q(x)
(4.4)

Relationship to cross-entropy: KL divergence equals cross-entropy minus entropy. Start with the definition:

DKL(p∥q)=∑xp(x)log2p(x)q(x)

Use logarithm properties (log(a/b) = log(a) − log(b)):

DKL(p∥q)=∑xp(x)[log2p(x)−log2q(x)]

Distribute the sum:

DKL(p∥q)=∑xp(x)log2p(x)−∑xp(x)log2q(x)

Recognize entropy and cross-entropy:

DKL(p∥q)=−H(p)+H(p,q)=H(p,q)−H(p)

Asymmetry and why it matters: KL divergence is not symmetric: DKL(p ∥ q) ≠ DKL(q ∥ p). The double bar notation ∥ emphasizes that direction matters. This asymmetry is important because it determines which errors the measure is sensitive to. DKL(p ∥ q) heavily penalizes cases where p assigns probability to events that q thinks are impossible. In generative AI evaluation, you typically compute DKL(real ∥ generated), which penalizes the model for missing modes that exist in real data. The reverse, DKL(generated ∥ real), would instead penalize the model for generating things that never appear in real data. The choice of direction depends on which failure mode you care about more.

Other properties: KL divergence is always non-negative and equals zero only when p = q. It is not a geometric distance because it does not satisfy the triangle inequality. When p is fixed, minimizing cross-entropy also minimizes KL divergence because H(p) is constant.

Connection to generative AI

Training: Language models minimize cross-entropy loss during training. For a one-hot target (the correct next token), cross-entropy becomes the negative log probability assigned to that token. Averaging over all training examples gives the negative log-likelihood from lesson 3. Minimizing cross-entropy is equivalent to maximum likelihood estimation.

Evaluation: Lower cross-entropy on test data indicates the model assigns higher probability to actual sequences. This measures how well the model predicts real text.

RLHF (Reinforcement Learning from Human Feedback): When fine-tuning models like ChatGPT, a KL divergence penalty keeps the fine-tuned model close to the original base model. This prevents the model from drifting too far and producing nonsensical outputs just to maximize reward.

Comparing distributions: KL divergence can compare whether two samples likely came from the same distribution. If KL divergence is small, the distributions are similar. If large, they differ significantly.
