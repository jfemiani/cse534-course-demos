Why structured output matters

So far, the model has returned ordinary text for a person to read. Programs often need information in a predictable form instead.

Suppose a program needs a task title, a due date, an estimated number of minutes, and a list of things to submit. A paragraph might contain that information, but another part of the program would have to guess where each piece begins and ends.

In this demonstration, a Pydantic class named CourseTask lists the fields the program expects. Pydantic is a Python package that checks whether data has the expected fields and types. For example, it can check that estimated_minutes is a number rather than a sentence.

The model’s reply is converted into a CourseTask object. The program can then use its fields directly. This is called structured output.

Pydantic can check the form of the answer, but it cannot prove that the answer is true. A correctly formatted due date can still be the wrong due date.
