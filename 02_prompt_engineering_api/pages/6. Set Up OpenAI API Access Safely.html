Install the Module 2 packages

Create a working folder on your computer for this module. Download requirements-module-02.txt into that folder. Open a terminal in the same folder, activate the virtual environment you created in Module 1, and run:

python -m pip install -r requirements-module-02.txt

This small requirements file installs openai and pydantic, the only third-party packages used by the four demonstrations.

Store the key in an environment variable

An environment variable is a named value stored by your operating system for programs to read. It keeps the key out of the Python file. The OpenAI Python SDK automatically looks for one named OPENAI_API_KEY. Replace your-key-here below with your actual key. Do this only in your own terminal; never paste the key into Canvas.

Linux or macOS (bash/zsh)

export OPENAI_API_KEY="your-key-here"

export OPENAI_MODEL="gpt-5.6"

Windows Command Prompt (cmd)

set OPENAI_API_KEY=your-key-here

set OPENAI_MODEL=gpt-5.6

Windows PowerShell

$env:OPENAI_API_KEY="your-key-here"

$env:OPENAI_MODEL="gpt-5.6"

These commands set variables for the current terminal session. If you close the terminal, set them again in the new session. Your instructor may recommend a different currently available model; if so, change OPENAI_MODEL, not the Python files.

Verify without revealing the key

Run this command. It reports whether the variable exists but does not print the secret:

python -c "import os; print('API key found' if os.getenv('OPENAI_API_KEY') else 'API key missing')"

If you capture a screenshot or recording, confirm that it shows only API key found—not the key itself.

Where the key must never appear

  • Python source code or a Jupyter notebook
  • Canvas text, comments, submissions, screenshots, or recordings
  • Email, chat, or discussion posts
  • A Git or GitHub repository, including a private repository

If you accidentally expose a key, revoke it immediately on the OpenAI Platform and create a new one.

See OpenAI’s current API key safety guidance.
