Optional: make terminal output easier to read

Demos 4 and 5 are optional. They do not introduce a new OpenAI API feature. They show how the Python package Rich can make text in a terminal easier to read.

Use these demonstrations if you want a more polished terminal interface. Skipping them will not prevent you from understanding Demo 6.

Demo 4: Rich basics

Instructor walkthrough: Demo 4

This first program does not call an AI model and does not cost anything to run. It introduces three Rich tools:

  • Console.print(...) prints styled text.
  • Markdown(...) turns Markdown headings, emphasis, and code into formatted terminal output.
  • track(...) displays progress while a loop runs.

Open the source file: 01_responses/04_rich_basics.py.

Run it with python 04_rich_basics.py. Look at the styled heading, rendered Markdown, and progress display. Then compare those results with ordinary print(...) output.

Prompt you can reuse later

Why this is called an evergreen prompt: You can reuse this prompt later. It tells a coding assistant exactly what the example must demonstrate, even if the Rich package changes.

Create a short, easy-to-follow Python program named 04_rich_basics.py. Introduce Rich without making an AI model request. Use Console once for styled text, Markdown once for formatted content, and track around a three-iteration loop. Keep the program short enough to explain line by line. Explain that these tools change how information looks in the terminal.

Demo 5: Add Rich formatting to the chat

Instructor walkthrough: Demo 5

This program begins with the conversation from Demo 2. It still sends the text you type to OpenAI and remembers the previous reply. The only new feature is how the conversation looks in the terminal.

Console.input(...) displays a styled You: prompt. Here, “prompt” means the label asking you to type—not the instructions sent to the AI model. Whatever you type after that label becomes the model input.

Markdown(response.output_text) formats Markdown in the model’s reply. For example, headings, bold text, lists, and code may be easier to read.

Open the source file: 01_responses/05_rich_chat.py.

Run it with python 05_rich_chat.py. Ask the model to reply with a heading, a short list, and one line of code. Then compare the formatted result with the plain-text chat from Demo 2.

Prompt you can reuse later

Why this is called an evergreen prompt: You can reuse this prompt later. It tells a coding assistant to add terminal formatting without changing how the program talks to OpenAI or remembers the conversation.

Create a short, easy-to-follow Python program named 05_rich_chat.py. Begin with the chat program from Demo 2. Use Rich Console for the You: and Assistant: labels, and use Markdown to display the model’s reply. Do not add panels, layouts, or live displays. Explain that Rich changes only how the conversation looks; it does not change the conversation history or the OpenAI API response.

What to remember

  • Rich is a display tool. It does not make the AI model smarter.
  • Demo 4 makes no paid API call.
  • Demo 5 makes one paid API call each time you submit a message.
  • Formatting the reply does not change what OpenAI returned.
