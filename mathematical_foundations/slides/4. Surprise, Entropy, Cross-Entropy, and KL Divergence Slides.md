# Entropy, Cross-Entropy, and KL Divergence

**Information Theory for Generative AI**

---

## Surprise and Information

**Example:** Language model sees "The capital of France is ..."
- High probability on "Paris" → not surprising
- Tiny probability on "banana" → very surprising!

<!-- stop -->

**Goal:** Define **information I(x)** to measure surprise
- Rare events are more surprising → carry more information
- Common events are less surprising → carry less information

---

## Properties of Information

**What properties should I(x) have?**

1. **Rare events carry more information:** `p(x) < p(y) ⟹ I(x) > I(y)`
2. **Certainty carries no information:** `p(x) = 1 ⟹ I(x) = 0`
3. **Independent events add:** `I(x,y) = I(x) + I(y)` **(when independent)**
4. **Continuous:** Small changes in `p` → small changes in `I`

<!-- stop -->

**These properties force a specific mathematical form:**
- Property 3 requires: `f(p₁·p₂) = f(p₁) + f(p₂)`

<!-- stop -->

- Only logarithms satisfy this: `log(ab) = log(a) + log(b)`

<!-- stop -->

- Thus, `I(x) = -log(p(x))` (negative log of probability)

<!-- stop -->

- A negative sign makes sure _less_ probable events are _more_ informative

---

## Self-Information

**Definition:**

```
I(x) = -log₂ p(x)
```

Measured in **bits** (base-2 logarithm)
- One bit = one yes/no question to identify the outcome
- **Alternative:** Natural log (ln) gives **nats** - often used for mathematical convenience
- Choice of base doesn't change the concepts, just the units

<!-- stop -->

**Examples:**
- p(x) = 1/2  →  I(x) = 1 bit
- p(x) = 1/4  →  I(x) = 2 bits
- p(x) = 1    →  I(x) = 0 bits (no surprise!)

<!-- stop -->

✓ Satisfies all four properties

<!-- stop -->

**Foundation of information theory:**
- Claude Shannon (1948): "A Mathematical Theory of Communication"
- Basis for data compression (ZIP, gzip), error correction, cryptography

---

## Entropy: Average Surprise

**Definition:** Expected value of self-information

Expected value = weighted average:
```
E[I(x)] = ∑ p(x) · I(x)
        = ∑ p(x) · (-log₂ p(x))
```

<!-- stop -->

**Final form:**
```
H(p) = -∑ p(x) log₂ p(x)
       x∈𝒳
```

Sum over **sample space** 𝒳 (all possible outcomes)

E.g. H(p) = -p(cat) log₂ p(cat) - p(dog) log₂ p(dog) - p(bird) log₂ p(bird),

Assuming you know the probability of the word being "cat", "dog", or "bird" ....

<!-- stop -->

**Properties:**
- Minimum entropy: One outcome has p=1 → H = 0 (no uncertainty)
- More uncertainty → higher entropy
- Maximum entropy: **uniform distribution**

---

## Maximum Entropy

**What is the maximum entropy?**

Uniform distribution over n outcomes: p(x) = 1/n for all x  
But how many bits of information is that?

<!-- stop -->

**Step 1:** Start with entropy formula
```
H = -∑ (1/n) log₂(1/n)
    i=1
```

<!-- stop -->

**Step 2:** Pull constant out of sum
```
H = -(1/n) ∑ log₂(1/n)
           i=1
```

<!-- stop -->

**Step 3:** Sum has n identical terms
```
H = -(1/n) · n · log₂(1/n)
```

---

## Maximum Entropy (continued)

**Step 4:** Simplify
```
H = -log₂(1/n)
```

<!-- stop -->

**Step 5:** Use log property: log(1/n) = -log(n)
```
H = log₂(n)
```

<!-- stop -->

**Result:** Maximum entropy = log₂(n) bits

**Example:** Vocabulary of 50,000 tokens 
- Uniform distribution: H = log₂(50000) ≈ 15.6 bits (a short integer)
- Any non-uniform distribution: H < 15.6 bits

---

## Cross-Entropy: Model Surprise

**Measures how surprised a model is by real data**
- p = true data distribution
- q = model's predicted distribution

```
H(p,q) = -∑ p(x) log₂ q(x)
         x∈𝒳
```

<!-- stop -->

**Interpretation:**
- If q = p (perfect model) → H(p,q) = H(p)
- If q ≠ p (imperfect model) → H(p,q) > H(p)

---

## Cross-Entropy (continued)

**Training:** Neural networks minimize cross-entropy loss

**Example training data:**
- Sample 1: "Jim has a pet [cat]"
- Sample 2: "Jim has a pet [dog]"
- Millions more sentences...

<!-- stop -->

**For a single prediction** (e.g., predicting next token after "pet"):
- Ground truth p(x) = one-hot vector (a **probability distribution**!)
  ```
  [0, 0, ..., 1, ..., 0]  ← p(correct token) = 1, p(others) = 0
  ```
- Model output: predicted probabilities q(x) for all tokens

<!-- stop -->

**Cross-entropy for this example:**
```
H(p,q) = -∑ p(x) log₂ q(x)  ← sum over sample space (all vocabulary)
         x∈𝒳
```
- Only one term survives: where p(x) = 1
- For one-hot targets: **-log q(correct token)**
- Sample 1: **-log q(cat)**
- Sample 2: **-log q(dog)**

<!-- stop -->

**Full training loss - average over all positions:**
```
Loss = (1/N) ∑ -log q(y_i)  ← sum over training positions i=1..N
            i=1
```
where y_i is the correct token at position i

<!-- stop -->

**Key insight: Empirical estimation**
- p (true distribution): **count frequencies in training data**
- q (model distribution): **model's predictions**
- The (1/N) ∑ formula is the **empirical cross-entropy**
- We don't need to know the "true" p - we estimate it from data!

---

## Cross-Entropy (continued)

**Used in virtually all neural networks:**
- BERT (2018), GPT-2/3/4 (2019-2023), LLaMA (2023)
- Image classifiers: ResNet, Vision Transformers
- Any model trained with softmax + cross-entropy loss

---

## KL Divergence: Extra Surprise

**Measures extra surprise from using q instead of p**

```
D_KL(p ∥ q) = ∑ p(x) log₂(p(x)/q(x))
              x∈𝒳
```

<!-- stop -->

**Key properties:**
- Always non-negative: D_KL(p ∥ q) ≥ 0
- Zero only when p = q
- **NOT symmetric:** D_KL(p ∥ q) ≠ D_KL(q ∥ p)
- Double bar ∥ emphasizes direction matters

<!-- stop -->

**Why asymmetry matters:**
- D_KL(real ∥ generated) penalizes missing modes (peaks/clusters) in real data
- D_KL(generated ∥ real) penalizes generating impossible things
- Choose direction based on which error matters more

---

## KL Divergence (continued)

**Critical to understanding these influential works:**

<!-- stop -->

- **Variational Autoencoders (VAEs)** - Kingma & Welling (2013): KL divergence in latent space

<!-- stop -->

- **InstructGPT/ChatGPT** - OpenAI (2022): KL penalty in RLHF keeps model aligned

<!-- stop -->

- **Knowledge Distillation** - Hinton et al. (2015): Student learns from teacher via KL

<!-- stop -->

- **Diffusion Models** - Ho et al. (2020): KL divergence in reverse process

---

## KL = Cross-Entropy - Entropy

**Derivation:**

Step 1: Start with definition
```
D_KL(p ∥ q) = ∑ p(x) log₂(p(x)/q(x))
              x
```

<!-- stop -->

Step 2: Use log property log(a/b) = log(a) - log(b)
```
D_KL(p ∥ q) = ∑ p(x)[log₂ p(x) - log₂ q(x)]
              x
```

<!-- stop -->

Step 3: Distribute the sum
```
D_KL(p ∥ q) = ∑ p(x) log₂ p(x) - ∑ p(x) log₂ q(x)
              x                   x
```

---

## KL = Cross-Entropy - Entropy (continued)

Step 4: Recognize entropy and cross-entropy
```
D_KL(p ∥ q) = -H(p) + H(p,q)
```

<!-- stop -->

Step 5: Rearrange
```
D_KL(p ∥ q) = H(p,q) - H(p)
```

<!-- stop -->

**Result:** KL divergence is the extra surprise beyond entropy

**For training:** When H(p) is constant, minimizing H(p,q) also minimizes D_KL(p ∥ q)

---

## Generative AI Applications

**Training:**
- Minimize cross-entropy = maximize likelihood
- For one-hot targets: -log q(correct token)
- Average over data = negative log-likelihood

---

## Generative AI Applications (continued)

**Evaluation:**
- Lower H(p,q) on test data = better predictions
- Perplexity = 2^H(p,q)
  - "How many equally-likely choices is the model confused between?"
  - Example: perplexity 32 = model considering ~32 plausible next words
  - Lower is better -- easier to interpret than cross-entropy = 5
- **Standard metric:** All GPT models, language model benchmarks report perplexity

---

## Generative AI Applications (continued)

**RLHF (Reinforcement Learning from Human Feedback):**
- KL penalty keeps fine-tuned model close to base model
- Prevents drifting too far and producing nonsense
- Balance: maximize reward while minimizing D_KL(finetuned ∥ base)

<!-- stop -->

**Distribution comparison:**
- Small D_KL → distributions similar
- Large D_KL → distributions very different

## The Demo: Comparing Text Distributions

**Goal:** Compare token frequency distributions from different texts

**Sources:**
1. p = Pride and Prejudice (English novel)
2. q_same = Alice in Wonderland (English novel)
3. q_diff = Django source code (Python code)

<!-- stop -->

**What we'll compute:**
- H(p), H(q_same), H(q_diff) - individual entropies
- H(p, q_same) and D_KL(p ∥ q_same) - similar sources
- H(p, q_diff) and D_KL(p ∥ q_diff) - different sources

<!-- stop -->

**Expected result:**
- Similar sources (both English) → small D_KL
- Different sources (English vs code) → large D_KL

---

## Code Walkthrough: Part 1 - Setup

```python
import numpy as np
import tiktoken
from urllib.request import urlopen

# Fetch text from different sources
url_p = "https://www.gutenberg.org/files/1342/1342-0.txt"      # Pride and Prejudice
url_same = "https://www.gutenberg.org/files/11/11-0.txt"       # Alice in Wonderland
url_diff = "https://raw.githubusercontent.com/django/django/main/django/db/models/query.py"

with urlopen(url_p) as response:
    text_p = response.read().decode('utf-8')[:50000]
with urlopen(url_same) as response:
    text_same = response.read().decode('utf-8')[:50000]
with urlopen(url_diff) as response:
    text_diff = response.read().decode('utf-8')[:50000]
```

<!-- stop -->

**What this does:**
- Fetches 50K characters from each source
- Two English novels + one Python source file

---

## Code Walkthrough: Part 2 - Tokenization

```python
# Tokenize using GPT-4 tokenizer
enc = tiktoken.get_encoding("cl100k_base")
tokens_p = np.array(enc.encode(text_p))
tokens_same = np.array(enc.encode(text_same))
tokens_diff = np.array(enc.encode(text_diff))
```

<!-- stop -->

**What this does:**
- Uses GPT-4's tokenizer (not simple characters!)
- Converts text → token IDs
- Same tokenization AI models use

<!-- stop -->

```python
# Build probability distributions
max_token = max(tokens_p.max(), tokens_same.max(), tokens_diff.max())
p = np.bincount(tokens_p, minlength=max_token+1) / len(tokens_p)
q_same = np.bincount(tokens_same, minlength=max_token+1) / len(tokens_same)
q_diff = np.bincount(tokens_diff, minlength=max_token+1) / len(tokens_diff)
```

<!-- stop -->

**What this does:**
- **np.bincount:** counts how many times each token ID appears
- **minlength:** ensures all arrays have same length (needed for element-wise comparison)
- **Division by len():** normalizes counts → probabilities (sum = 1)

---

## Code Walkthrough: Part 3 - Entropy

```python
# Individual entropies (not measuring similarity)
H_p = -np.sum(p[p > 0] * np.log2(p[p > 0]))
H_same = -np.sum(q_same[q_same > 0] * np.log2(q_same[q_same > 0]))
H_diff = -np.sum(q_diff[q_diff > 0] * np.log2(q_diff[q_diff > 0]))
```

<!-- stop -->

**What this does:**
- Computes H(p) = -∑ p(x) log₂ p(x)
- Only sum over tokens that appear (p > 0)
- **Why filter p > 0?** log₂(0) is undefined (-∞)
  - By convention: 0·log(0) = 0 (no contribution to entropy)
  - Filtering is cleaner than special-casing

<!-- stop -->

**Output from running this:**
```
H(p) = 9.2924 bits
H(q_same) = 8.8703 bits
H(q_diff) = 8.7408 bits
```

Each distribution has ~9 bits of uncertainty per token

**Context:** These are token-level (not character-level) entropies
- Tokens are larger units than characters (words, subwords)
- Higher entropy than character-level (~1-2 bits) is expected

---

## Code Walkthrough: Part 4 - Cross-Entropy & KL

```python
# Cross-entropy and KL divergence (measuring similarity)
print("Comparing p with q_same (similar sources):")
mask_same = p > 0
H_p_qsame = -np.sum(p[mask_same] * np.log2(np.clip(q_same[mask_same], 1e-10, None)))
D_kl_same = np.sum(p[mask_same] * np.log2(p[mask_same] / np.clip(q_same[mask_same], 1e-10, None)))
```

<!-- stop -->

**What this does:**
- H(p, q_same) = -∑ p(x) log₂ q_same(x)
- D_KL(p ∥ q_same) = ∑ p(x) log₂(p(x)/q_same(x))
- **np.clip to 1e-10:** prevents log₂(0) when q assigns zero probability
  - 1e-10 is tiny but finite → log₂(1e-10) ≈ -33 bits (very surprising!)
  - Handles vocabulary mismatch (token in p but not in q)
- Only sum where p(x) > 0

<!-- stop -->

**Output (similar sources):**
```
Comparing p with q_same (similar sources):
  H(p, q_same) = 15.9590 bits
  D_KL(p || q_same) = 6.6666 bits
```

Verify: D_KL = H(p,q) - H(p) = 15.96 - 9.29 = 6.67 ✓

---

## Code Walkthrough: Part 5 - Different Sources

```python
print("Comparing p with q_diff (different sources):")
mask_diff = p > 0
H_p_qdiff = -np.sum(p[mask_diff] * np.log2(np.clip(q_diff[mask_diff], 1e-10, None)))
D_kl_diff = np.sum(p[mask_diff] * np.log2(p[mask_diff] / np.clip(q_diff[mask_diff], 1e-10, None)))
```

<!-- stop -->

**Output (different sources):**
```
Comparing p with q_diff (different sources):
  H(p, q_diff) = 21.8579 bits
  D_KL(p || q_diff) = 12.5656 bits
```

<!-- stop -->

**Interpretation:**
- Similar sources: D_KL = 6.67 bits
- Different sources: D_KL = 12.57 bits (almost 2×!)
- English novels are much more similar to each other than to Python code
- Higher D_KL means distributions are more different

**Rule of thumb:** D_KL > 10 bits → very different distributions

## Summary

**Four key concepts:**

1. **Self-Information:** I(x) = -log₂ p(x) - surprise of one outcome
2. **Entropy:** H(p) = -∑ p(x) log₂ p(x) - average surprise
3. **Cross-Entropy:** H(p,q) = -∑ p(x) log₂ q(x) - model's surprise on real data
4. **KL Divergence:** D_KL(p ∥ q) = H(p,q) - H(p) - extra surprise from using q

<!-- stop -->

**AI applications:**
- Training: minimize cross-entropy loss
- Evaluation: measure perplexity
- RLHF: KL penalty prevents drift
- Comparing distributions: KL divergence

<!-- stop -->

**Key relationship:** D_KL(p ∥ q) = H(p,q) - H(p)
