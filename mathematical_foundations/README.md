# Mathematical Foundations demonstrations

These reviewed demonstrations accompany the CSE 534 Mathematical Foundations module. Each program first shows individual generated rows and then summarizes the larger sample in a graph.

## Demos

1. [Continuous uniform sampling](01_uniform) — values from an interval, a DataFrame preview, interval counts, and a histogram.
2. [Bernoulli sampling](02_bernoulli) — 0/1 trials, a DataFrame preview, and expected-versus-observed probabilities.
3. [Categorical sampling](03_categorical) — one choice among several named categories, a DataFrame preview, and a comparison bar chart.

Each folder contains the reviewed Python file and a PROMPT.md file. The prompt is optional: use it to regenerate the code or ask an AI assistant for another explanation, then compare the result with the reviewed file.

## Install the packages

Download [requirements-math-foundations.txt](requirements-math-foundations.txt), open a terminal in this folder, and run:

    python -m pip install -r requirements-math-foundations.txt

The older direct copies of the Python files remain at this folder's top level because existing Canvas links use them. The per-demo folders above are the organized source going forward.
